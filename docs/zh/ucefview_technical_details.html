技术细节

本文档概述 UCefView 插件的架构、模块和关键组件。

架构

插件采用分层架构，以便保持模块化和可维护性：

  1. Chromium Embedded Framework (CEF)： 由独立 XCefHost 进程承载的浏览器引擎。
  2. XCef： 通过稳定 C ABI 暴露浏览器能力的原生库；CEF 生命周期、渲染和浏览器回调由 XCefHost 负责。
  3. UCefView Plugin： 使用 XCef 的 Unreal Engine 模块，提供 SCefView、UCefView、Blueprint 库和引擎渲染集成。

模块

插件包含两个主要模块：

模块 描述
UCefView 主插件模块，包含 Unreal Engine 集成代码，包括 UMG/Slate widget、Blueprint 函数库和资源类型。
UCefViewEditor 项目设置、SDK 目录/下载/安装、共享 SDK 路径解析和 Editor 错误弹窗；不进入打包游戏。

XCef 是动态加载的原生 SDK，不是 Unreal 模块。插件在 Source/ThirdParty/XCef/include 中保留一份跨平台头文件，SDK 运行文件另行安装。

Editor 目标中，UCefView 依赖 UCefViewEditor，通过 FUCefViewEditorModule::GetXCefSdkDirectory 获取所选运行目录的绝对路径。Editor 模块独立解析项目配置，不依赖设置 UI 或目录加载。UCefViewEditor 不反向依赖 UCefView，通过反射注册 runtime 设置对象。

两个模块各自实现包标识和必需文件检查。Editor 模块负责 Slate 错误弹窗；runtime 加载只报告错误，不显示 UI。Editor 构建不暂存 SDK 文件，Live Coding 也一样。

Game 目标不依赖 UCefViewEditor。UBT 将所选 SDK 复制到 <Project>/Binaries/ThirdParty/XCef/<平台[/架构]>，UAT 再将其作为 NonUFS 文件打包。打包游戏相对游戏项目目录定位这份副本。配置及运行目录详见 XCef SDK 管理 。

分发

本地 publish 先执行 BuildPlugin，再生成配置的各 Unreal 版本源码 ZIP。BuildPlugin 输出保留编译后的二进制和预编译构建文件；源码 ZIP 包含 Source、Content、Resources、Config、Docs 及选定的分发脚本，不包含 Binaries 和 Intermediate。

PublishPlugin.ps1 -SkipUpload 执行本地流程并跳过上传。为某个 Unreal 版本生成 ZIP 只会调整描述文件；实际编译的是传入构建步骤的引擎。其他引擎和平台需要分别验证。

关键 C++ 类

类 头文件 描述
UCefContext CefContext.h 管理 CEF 全局生命周期的 singleton。
UCefSettings CefSettings.h 可在 Project Settings 中配置的 UObject 设置，用于控制全局浏览器行为。
SCefView Slate/SCefView.h 用于 Slate UI 的核心 WebView widget。
UCefView UMG/UCefView.h UMG widget，对 SCefView 进行包装，使其可在 Widget Blueprint 中使用。
UCefViewEvent CefViewEvent.h 用于从 C++ 向 JavaScript 发送事件和数据的辅助类。
UCefViewQuery CefViewQuery.h 用于 JavaScript 与 C++ 异步请求/响应通信的辅助类。
FCefViewSettings Slate/SCefViewSettings.h 包含单个 WebView 实例设置的结构体。
CefViewTypes CefViewTypes.h 包含插件中常用枚举和类型定义。

Blueprints

插件包含多个预置 Blueprint 资源，位于 UCefView Content 目录。

Widgets

  • **WBP_CefView**：直接封装 UCefView 组件的简单 widget。
  • **WBP_CefViewBrowserTab**：完整浏览器 tab widget，包含地址栏和 Back、Forward、Reload 控件。
  • **WBP_CefViewSingleTabBrowserWindow**：完整单标签浏览器窗口示例。
  • **WBP_CefViewMultipleTabBrowserWindow**：完整多标签浏览器窗口示例。

Actors

  • **ACefView**：可放置在场景中的 Actor，用于在 static mesh component 上显示 WebView。
  • **ACefViewSingleTabBrowser**：演示如何在 3D 世界中使用浏览器 widget 的示例 Actor。

Materials

  • **sRGBToLinear**：用于将 WebView 纹理从 sRGB 转换到 Linear 色彩空间的材质函数，以便在 Unreal 渲染管线中获得正确颜色。
