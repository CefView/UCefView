互操作

UCefView 提供原生 Unreal Engine 环境（C++/Blueprint）与 Web 环境（JavaScript）之间的互操作能力。你可以从 C++ 调用 JavaScript，也可以从 JavaScript 调用 C++/Blueprint，从而构建混合式应用。

UCefViewBridge 对象

为了实现通信，UCefView 会自动向 Web 页面注入一个 bridge 对象到 window 上。网页可以通过它与 Unreal 应用交互。

该对象名称可在项目的 UCefView Settings 中通过 BridgeObjectName 配置，默认名称为 UCefViewBridge。

UCefViewBridge API

方法 描述
addEventListener(eventName, listener) 注册一个监听函数，用于接收 C++ 触发的指定事件。
removeEventListener(eventName, listener) 移除已注册的事件监听函数。
invoke(methodName, ...args) 使用指定方法名和参数调用原生 C++/Blueprint 处理器。

C++ 到 JavaScript

直接执行 JavaScript

你可以从 C++ 在 WebView 上下文中执行任意 JavaScript 代码。

// Assume you have a pointer to a UCefView widget
UCefView* MyUCefView;
MyUCefView->ExecuteJavascript(
UCefView::MainFrameID,
TEXT("alert('hello Unreal')"),
TEXT("")
);

触发事件

你可以在 JavaScript 中注册事件，然后从 C++ 或 Blueprint 触发该事件。

在 JavaScript 中注册事件处理器

function onLoad() {
window.UCefViewBridge.addEventListener(
"colorChange",
function (color) {
document.getElementById("main").style.backgroundColor = color;
}
);
}

从 C++ 或 Blueprint 触发事件

UCefView* MyUCefView;
UCefViewEvent* ColorChangeEvent = NewObject<UCefViewEvent>();
ColorChangeEvent->Name = TEXT("colorChange");
ColorChangeEvent->SetArguments(TEXT("[red]"));
MyUCefView->BroadcastEvent(ColorChangeEvent);

JavaScript 到 C++

UCefViewBridge.invoke

你可以从 C++/Blueprint 注册 invoke handler，然后从 JavaScript 调用。

在 C++/Blueprint 中注册 invoke handler

class UWebClient : public UObject
{
GENERATED_BODY()
public:
void InvokeHandler(const int64& InBrowserId,
const FCefFrameId& InFrameId,
const FString& InMethod,
const FString& InArguments)
{
if (InMethod == "HelloNative") {
// InArguments: "[1, \"2\", true]"
}
}
};
UCefView* MyUCefView = NewObject<UCefView>();

MyUCefView->OnInvokeMethod.AddDynamic(MyWebClient, &UWebClient::InvokeHandler);

window.cefViewQuery(query)

你可以注册 CefViewQuery handler 来处理 JavaScript 发起的请求，并返回响应。

在 C++/Blueprint 中注册 CefViewQuery handler

UCLASS()
class UWebClient : public UObject
{
GENERATED_BODY()
public:
void CefViewQueryHanlder(const int64& InBrowserId,
const FCefFrameId& InFrameId,
UCefViewQuery* InQuery)
{
FString Request = InQuery->GetRequest();
InQuery->ErrorCode = 0;
InQuery->Response = TEXT("ok");
InQuery->IsSuccess = true;
InQuery->Reply();
}
};
UCefView* MyUCefView = NewObject<UCefView>();
UWebClient* MyWebClient = NewObject<UWebClient>();
MyUCefView->OnInvokeMethod.AddDynamic(MyWebClient, &UWebClient::CefViewQueryHanlder);

从 JavaScript 发送 CefViewQuery 请求并处理响应

var query = {
request: "hello from CefViewQuery",
onSuccess: function (response) {
alert("Success: " + response);
},
onFailure: function (error_code, error_message) {
alert("Failure: " + error_message + " (Error Code: " + error_code + ")");
},
};
window.cefViewQuery(query);
