更换 CEF 版本

UCefView 允许你根据项目需求更换底层 Chromium Embedded Framework (CEF) 版本。无论是为了使用新的 Web 特性、获取安全修复，还是匹配特定 Chromium 版本，都可以切换插件使用的 CEF 二进制文件。本指南会说明完整流程。

1. 选择 CEF 版本

  1. 访问 CEF Builds 页面。 > [!note] > 该页面提供 Stable、Beta、Dev 等不同分支。生产项目强烈建议选择 Stable 构建。
  2. 根据项目需求选择合适的 CEF 版本。
  3. 复制完整版本字符串，例如：126.2.18+g3647d39+chromium-126.0.6478.183。
警告
更换版本前，建议先查看 CefViewCore 仓库提交历史，确认目标 CEF 版本是否已被测试和支持。大版本升级可能包含 CEF API 破坏性变更，需要同步更新 CefViewCore wrapper。

2. 更新脚本配置文件

  1. 打开更新脚本使用的配置文件： > UCefView/Scripts/UpdateThirdparty/ThirdParty-Config.txt

  2. 将 CEF_VERSION 更新为上一步复制的版本字符串。

    ini CORE_REPO=https://github.com/CefView/CefViewCore.git CORE_VERSION=8b618d4290c9187eedfb8b176aae8a7dfcaa51ab CORE_BUILD_TYPE=Release CEF_HELPER_NAME=UCefViewHelper CEF_VERSION=126.2.18+g3647d39+chromium-126.0.6478.183

警告
如果跨越较大的 CEF 版本区间，可能还需要将 CORE_VERSION 更新到支持新 CEF API 的提交。请查看 CefViewCore 仓库选择匹配版本。

3. 运行更新脚本

运行当前操作系统对应的脚本。该脚本会下载指定 CEF 二进制文件，并重新编译 CefViewCore。

  • Windows： powershell @section autotoc_md44 From the UCefView/Scripts/UpdateThirdparty/ directory ./Update-Thirdparty.ps1
  • macOS 或 Linux： bash @section autotoc_md45 From the UCefView/Scripts/UpdateThirdparty/ directory ./Update-Thirdparty.sh

4. 验证更新

脚本成功完成后，启动 Unreal Engine 项目。新的 CEF 版本会在引擎启动时输出到日志中。

可以搜索日志：LogUCefView: Using CEF version。

5. 排查问题

  • 构建失败： 如果 Update-Thirdparty 脚本在编译 CefViewCore 时失败，通常是 CEF_VERSION 与 CORE_VERSION 不匹配。请确认二者兼容。
  • 运行时错误： 如果项目启动时崩溃，请检查日志中与 CEF framework 或 UCefView 插件模块加载相关的错误。
