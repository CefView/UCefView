快速开始

1. 安装

  1. 从 Fab 安装 UCefView 到对应版本的 Unreal Engine，并在需要使用的项目中启用。源码分发包也可以放到 <Project>/Plugins/UCefView。
  2. 在插件窗口中确认插件已启用（Edit -> Plugins）。
  3. 打开 **Edit > Project Settings > Engine > UCefView Settings > XCef SDK**，刷新目录，下载并安装兼容的 SDK，然后选择 **Use for this project**。
  4. 重启 Editor 加载所选 SDK。切换 SDK 不需要重新编译项目；首次缺少 SDK 时，可以关闭错误提示并继续进入设置面板。

XCef SDK 与插件分开安装。UCefView 在 XCefHost 中运行 CEF，可以与 Unreal 内置 Web Browser 插件共存，无需再重命名引擎的 CEF3 目录。同一项目只启用一份 UCefView：使用 Engine 插件或项目插件其中之一。

Editor 和 PIE 直接加载所选共享 SDK。Editor 构建（包括 Live Coding）不会复制或清理它的运行文件。删除或修改共享 SDK 前，请关闭使用它的 Editor。

2. 项目设置

打开 Edit > Project Settings > Engine > UCefView Settings 配置项目级浏览器设置。常用设置包括：

UCefView Settings
  • Locale： 设置 CEF 浏览器区域语言。
  • User Agent： 设置浏览器请求使用的 user agent。
  • Accept Language List： 设置 Web 请求接受的语言列表。
  • Command Line Args： 传递给 CEF browser process 的额外命令行参数。
  • Builtin Scheme Name： 内置资源使用的 scheme 名称。
  • Bridge Object Name： C++/JavaScript 桥接对象名称。
  • Disable Sandbox： 是否禁用 XCefHost 中的 CEF 沙箱。
注解
macOS 平台上，CEF 不支持在主进程中启用 sandbox。若你要发布带 UCefView 的游戏产品，需要在生成的 Xcode 项目中关闭 App Sandbox。

更多细节请参考 UCefSettings 类。

3. 使用 SCefView (Slate)

  1. 在 Slate UI 中包含 SCefView.h。
  2. 创建 SCefView widget。
  3. 使用 SCefView::SetUrl 加载 URL。
  4. 使用 FCefViewSettings 配置 WebView 外观和行为。
  5. 绑定 SCefView::OnLoadStart、SCefView::OnLoadEnd、SCefView::OnConsoleMessage 等事件。
// In your .h file
#include "Slate/SCefView.h"
TSharedPtr<SCefView> MyWebView;
// In your .cpp file, inside a method like SNew
SNew(SCefView)
.Url(TEXT("https://www.google.com"))
.OnLoadStart(this, &SMyWidget::HandleLoadStart)
.OnLoadEnd(this, &SMyWidget::HandleLoadEnd)

4. 使用 UCefView (UMG)

  1. 打开 Widget Blueprint。
  2. 在 Palette 中搜索 UCefView 并拖入 widget 层级。
  3. 在 Details 面板设置 UCefView::Url 来加载页面。
  4. 根据需要调整可用属性。
  5. 绑定 UCefView::OnLoadStart、UCefView::OnLoadEnd、UCefView::OnConsoleMessage 等事件。

5. 使用 Blueprint

UCefView 提供了多个可直接参考或扩展的 Blueprint widget。

  • **WBP_CefView**：封装单个 UCefView 的基础 user widget。
  • **WBP_CefViewBrowserTab**：包含地址栏和后退、前进、刷新按钮的浏览器 tab widget。
  • **WBP_CefViewSingleTabBrowserWindow**：完整的单标签浏览器窗口。
  • **WBP_CefViewMultipleTabBrowserWindow**：完整的多标签浏览器窗口。

6. 游戏打包

安装目标平台和架构需要的 SDK，并将选择保存在项目的 Config/DefaultEngine.ini 中。构建机器必须已安装所选 SDK；UnrealBuildTool 不会自动下载。

Game 构建将所选运行文件复制到 <Project>/Binaries/ThirdParty/XCef/<平台[/架构]>，并以 NonUFS 散文件形式打包。分发时保留完整游戏输出及其中的运行文件。玩家无需安装 SDK 管理器、共享 SDK，也无需在首次启动时下载运行库。

Engine 插件和项目插件使用相同流程。重新构建运行文件前，请关闭正在运行的游戏。SDK 路径、版本选择和故障处理见 XCef SDK 管理 。
